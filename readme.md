# Script Utils
A repository for useful automation scripts I commonly use.

## Flutter
### 1. AppVersionExtraction
#### Availability
- ✅ Bash
- ✅ Powershell

This PowerShell script retrieves the version and build number information from a Flutter project's `pubspec.yaml` file and makes these values available for use in local development or CI/CD workflows.

## Common
### 1. Extract Changelog
#### Availability
- ✅ Bash
- ❌ Powershell

Extracts the changelog for a specified version and build from dev_changelog.md and formats it for display or workflow use.
